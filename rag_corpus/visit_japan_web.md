# Visit Japan Web / Entry Procedures

Visit Japan Web (vjw.digital.go.jp) provides a single, unified QR code covering both immigration and customs declarations, replacing the old separate paper forms at major airports. Joint Kiosks using this QR code are in place at Haneda, Narita, Kansai, and Fukuoka airports. Paper forms remain accepted everywhere as a fallback — the digital process is faster but not mandatory.

This is a factual, sourceable entry-logistics topic the app can answer directly. It should not be extended into legal or visa-eligibility determinations (see guardrails.md's scope boundary) — "do I need to use Visit Japan Web" is in scope; "will I be denied entry" is not.
