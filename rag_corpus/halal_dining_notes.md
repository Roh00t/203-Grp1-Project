# Halal Dining Practical Notes (Tokyo)

Halal certification status in Tokyo varies by venue and changes over time — multiple sources explicitly recommend confirming current certification directly with the restaurant rather than trusting any single listing indefinitely, including this one. A common hidden risk: traditional sushi rice is seasoned with mirin (a rice wine), so halal-certified sushi venues substitute a halal-compliant seasoning — worth mentioning explicitly to a dietary-constrained user rather than assuming "sushi" is safe by default.

Tokyo's clearest halal-dining clusters by area: Shibuya (yakiniku, Indonesian), Asakusa/Ueno (ramen, sushi), Shin-Okubo (highest density of halal eateries in the city, one stop from Shinjuku). This app's curated list (dietary_table.json) currently covers Asakusa and Shibuya only — Shin-Okubo is a known, real coverage gap, not an oversight to hide.
